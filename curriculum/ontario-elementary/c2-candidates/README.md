# Ontario Elementary C2 candidates

This directory is reserved for **reviewable, reference-only** `axiom-curriculum-standard-record.v2` candidates that have passed the narrow C2 intake verifier but have **not** been promoted into `records-v2`.

A candidate may be placed here only after:

1. the source has one valid current C1 lock;
2. current qualified-human source identity/scope review is `approved`;
3. current licensing evidence permits at least reference-only use;
4. operator-supplied source bytes exactly match the historical C1 SHA-256 and byte length; and
5. `tools/ontario_elementary_c2_intake.py verify-candidate` accepts the record in `reference-only` mode.

Candidate presence does not establish human normalization review, curriculum correctness, completeness, canonical promotion, deterministic pack readiness, signing, staging, activation, grade/credit authority, or Ministry approval.

The current repository intentionally contains no candidate JSON records because current source-review/licensing gates are still blocked. The README is not a candidate record and is ignored by candidate verifiers.
