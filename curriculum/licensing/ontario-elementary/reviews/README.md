# Ontario Elementary licensing review evidence

This directory stores **human licensing/redistribution attestations**, not Ontario curriculum source documents and not automatic permission grants.

Each review must bind to one exact target generated by:

```bash
python tools/ontario_elementary_licensing_review.py plan
```

A target is content-addressed to the current Ontario Elementary source-review target and C1 metadata lock. If the source identity, locator, source-entry digest, upstream document digest, or C1 lock changes, the old licensing review becomes stale and must not silently carry forward.

## Allowed decisions

- `verbatim-redistribution-permitted` — the reviewer records a basis supporting redistribution of source wording under the stated conditions. At least one evidence locator is required.
- `reference-only-use-permitted` — Axiom may preserve identifiers/provenance/reference structure without treating source wording as redistributable.
- `external-reference-only` — the source may be referenced externally but should not be incorporated as reusable source content.
- `prohibited` — the reviewed use is not permitted.
- `unresolved` — the reviewer cannot yet reach a supported conclusion.

A resolved decision requires all licensing confirmations and no open findings. Version 1 allows only one current attestation per source; duplicate current records fail closed rather than relying on filename or timestamp ordering.

## Review boundary

Public availability is **not** redistribution permission. A valid review record proves only that a named human reviewer made the recorded decision against the exact current target. The verifier does not decide copyright law and does not prove the reviewer's legal conclusion correct.

Licensing review is separate from:

- source identity/scope review;
- curriculum normalization or correctness;
- educator/cultural/accessibility review;
- assessment validity;
- deterministic pack verification;
- staging or activation;
- Ministry approval or endorsement.

No licensing approvals are currently committed in this directory. Do not add generated or machine-authored approval evidence.
