# Claw Academy legacy visual manifest

Status: recovered-source provenance registry. This file records legacy Claw visual evidence without making any recovered image canonical.

## Why this exists

Legacy C.L.A.W. Academy material contains conflicting character descriptions. Additional historical images are expected. Visual decisions therefore need provenance, comparison, and an explicit canon decision rather than first-image-wins inheritance.

A recovered image may influence future visual direction, but it does not become product canon merely because it survived.

## Ingestion rules for additional legacy art

For each recovered image, record:

1. stable reference ID;
2. source/date/context;
3. original filename or source locator;
4. exact file digest where available;
5. detected dimensions/media type;
6. observable visual facts;
7. text/image conflicts;
8. whether the image appears to depict a named legacy character and the evidence for that inference;
9. canon status: `non-canonical`, `candidate`, `approved`, or `superseded`;
10. any accessibility or child-safety concerns relevant to reuse.

Do not silently edit, recolour, crop, upscale, or regenerate a recovered source and then treat the derivative as the original reference. Derivatives should receive their own IDs and provenance.

## Canon-lock rule

A future visual or character bible should be locked only after:

- the recovered image set has been compared;
- major contradictions are explicitly resolved;
- the chosen design supports Claw's current experience architecture and accessibility requirements;
- characters do not require real-person identity or likeness data to function;
- the decision is explicitly approved rather than inferred from legacy frequency.

This manifest is evidence for a future creative decision, not that decision itself.
